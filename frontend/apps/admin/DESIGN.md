# Admin 界面约定

管理任务界面（Operate），面向企业内部管理员。视觉和结构按用户指定的 Ant Design Pro，使用现有 Vite 工程中的 Ant Design 与 ProComponents 实现。

## 布局与导航

- ProLayout 使用混合布局：顶部品牌、导航开关与退出操作；桌面左侧导航和右侧内容区，移动端使用抽屉导航。
- 品牌为 EnterpriseRag，产品入口名为“企业知识管理”。品牌图形使用 Ant Design 图标，无外链图片或装饰插画。
- `routes/admin-pages.tsx` 管理真实页面的路径、菜单、图标、标题、权限与加载入口。仅展示已经实现且当前有权访问的页面。
- PageContainer 提供面包屑、一级标题与说明。连接检查使用一个独立内容区，不展示虚构统计或未实现的操作入口。
- 登录、会话检查、无权限、404、500 为独立入口状态，不展示受保护的侧栏和页面数据。

## 主题与排版

- 中文、浅色、系统字体。根 ConfigProvider 负责主题，品牌蓝使用 `colorPrimary: #1765ad`；文本、次要文本、底色、边框等均来自正式 Token。
- ProLayout 的 header/pageContainer Token 控制框架尺寸；业务 CSS Modules 负责局部布局。无需全局覆盖组件库内部类名。
- 顶栏高 64，桌面侧栏宽 224；页面外侧间距 24。内容区留出清晰的标题、说明与操作层级；窄屏文案换行，主操作保持可见。
- 内容区圆角 12，连接表格按真实状态展示。登录表单宽度上限 408，手机保留 20px 外边距。

## 交互与可访问性

- 导航开关具备中文名称、展开状态和键盘操作；菜单链接标记当前页面。抽屉关闭后恢复开关焦点，点击菜单后关闭抽屉。
- 提供跳至内容入口、可见焦点、表单标签、错误恢复操作。装饰图标不进入菜单的可访问名称。
- 初始空态、请求中、确认成功、失败及重试均依据实际请求状态。会话失效、权限撤销或权限查询失败时撤下布局与内容。
- 当前只有本地测试身份源，登录页明确说明来源；飞书接入前不宣称企业 SSO 可用。

## 验证

`make frontend-e2e` 使用生产构建、真实后端与隔离数据库检查认证、导航、故障恢复和静态服务，并保存 1440/768/390/320 宽度截图。单元测试验证页面状态、路由、权限及共享消费者；范围与证据见 [实施记录](../../../docs/plan/V1.0-MVP/implementation/admin-pro-ui.md)。
