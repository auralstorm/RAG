# ADR-0008：单一企业内部部署并保留租户迁移路径

当前路线图以企业内部部署为早期范围，将完整多租户隔离放在 V2.0。需要确认企业客户之间是否共享同一部署：共享会影响全部资源归属、查询唯一约束、检索、缓存、存储、队列、凭据和审计，不能通过只增加 tenant_id 解决。

**采用方案 A：单一企业内部部署。** 用户已在本次会话确认。保留 V1.1/V1.3 已规划的可空 tenant_id；NULL 只表示尚未启用租户维度的本部署资源。V1.0 已有资源按明确映射在启用前回填，默认保持企业内用户/团队/KB 授权。完整隔离在实际需要时单独验收。

**未采用方案 B：多个企业客户共享部署。** 如以后变更为共享部署，在首个共享环境上线前，让所有租户资源具备非空归属并实施全链路隔离；必须重估版本范围、迁移及安全验收，不能允许 NULL 资源作为全租户共享默认值。

本决策确认产品部署模式，不表示租户迁移或多租户隔离已经实现。

两种方案都要求实施前明确隔离位、资源回填、唯一约束和测试，详见 [统一契约与跨版本演进规则](../architecture/统一契约与跨版本演进规则.md)。
