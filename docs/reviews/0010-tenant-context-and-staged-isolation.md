# ADR-0010：租户上下文与隔离采用可验证的分阶段迁移

V2.0 保留用户已确认的单企业部署，不因版本号自动转为多个客户共享平台。设计选择先建立可信租户上下文、存量归属和隔离测试，再按业务及数据要求评审共享表、独立 Schema 或独立数据库/部署；相较直接统一新增 tenant_id 并开放第二客户，这增加迁移和兼容工作，但能守住存量运行、外部幂等及完整隔离边界。

资源 ID、Agent/Workflow 快照和外部 operation_key 保持，新的租户限定查询与复合约束分阶段收紧；租户归属不能由 Prompt、普通请求参数或消息头自行宣称。特权跨租户管理采用明确 Scope、目的、短时授权和审计，不能用空 tenant_id 实现全局放行。

该方案是 [V2.0 开发包](../plan/V2.0-Enterprise-Grade-Platform/README.md) 的设计基础，生产启用前需依据实际数据、身份/客户关系和隔离要求评审接受。ADR-0008 的产品部署决定继续有效；本草案不批准共享部署，也不宣称仅靠字段已实现隔离。
