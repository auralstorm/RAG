# ADR-0013：所有版本采用单一企业内部部署

用户已确认同步全部文档，移除多租户需求与设计。V1.0–V2.0 均以单一企业内部的独立部署为产品范围，企业内部门、团队、用户组、知识库及 Workspace 沿用服务端身份、角色和资源授权；这一决定替代 ADR-0008，并撤回 ADR-0010。

删除 Tenant 实体、tenant_id、TenantContext、归属回填和多企业共享部署的接口、配额、计费、接入/退出及跨租户验收，不再要求为未来多租户预留字段或迁移路径。稳定资源 ID、模块接口及普通版本兼容迁移继续保留，Organization/Workspace 只表达企业内组织与协作授权，不承担企业客户隔离职责。

高可用、容量治理、系统/部门/用户/模型额度、审批与业务动作、数据删除与员工撤权、预算账本及灾备仍按现有业务目标交付。减少的工作集中在客户隔离与迁移，不以删减企业内部权限换取简化；如未来产品范围改变，再独立评估，当前不计入 Backlog 或验收。

本次更新的是设计基线。若实际实现已有相关字段或消费者，先盘点并形成兼容方案；文档同步不授权直接删除生产数据或数据库列。
