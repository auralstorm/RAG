# ADR-0007：Agent 执行契约采用增量演进

V1.3 的全量表清单漏列了 V1.1 的幂等、预算及输入输出字段。本文选择保留 V1.1 已有表、标识与字段，以新增列和显式映射承接 V1.2 的版本快照及 V1.3 的规划能力；相比直接替换表或改名，这会保留部分兼容字段，但能保持存量 Run、幂等约束和恢复路径。

该选择已体现在本轮文档修订中，正式实施前须由架构负责人依据实际数据库和迁移验证结果接受此 ADR；`proposed` 不表示已完成代码实现或生产迁移。

具体字段、公共状态、Definition 转换、API 兼容和验证要求以 [统一契约与跨版本演进规则](../architecture/统一契约与跨版本演进规则.md) 为设计权威源。V1.3 文档只列本版增量；删除兼容字段需消费者盘点、迁移窗口和新 ADR。

编号从 V1.0 已有 ADR-0001–0006 之后续接，避免重新使用已有决策编号。
