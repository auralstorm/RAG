# 04｜企业安全、制度与数据生命周期

> 版本：V2.0。复用 Identity/Policy/Audit/Secret 与既有生命周期；归属见 [01](01-organization-workspace-and-resource-authorization.md)，恢复见 [06](06-backup-disaster-recovery-and-upgrade-governance.md)，状态/API 见 [07](07-database-api-and-contract-design.md)。

## 1. 数据与授权

M0 明确适用企业制度/地区/数据分级、目的、保留期和处理方。Schema、资源标签与 Policy 表达访问/传输/脱敏/删除规则；模型地区和 Connector 凭据/网络约束在每次实际调用时校验。

用户、Agent、Workflow、Worker 和平台管理身份分开。跨组织/Workspace/资源访问需显式 Scope；客户端、Prompt 或缓存中的“管理员”字段不授予权限。授权撤销影响后续调用/恢复，即使旧 Token、审批或版本快照尚未过期。

高危身份溯源和高权限运维使用已有高权限、目的/原因、二次确认与审计，授权限制到目标资源和时间。只读审计员不获得凭据、原始 Trace 或业务写权限。

## 2. Secret 与网络

凭据引用归属于明确资源 Owner/环境/Connector 或模型配置。加密、轮换、读取与失效由受控 Secret Adapter 处理；业务正文、Schema、Prompt、普通日志/Trace 和 Snapshot 不复制明文 Secret。

轮换保持密钥版本引用、使用审计和恢复路径；旧加密产物/备份仍需的密钥不能因轮换直接丢失。密钥恢复与数据库备份分开授权/保存，验证实际解密/访问和故障范围，不假设配置有 key_id 就可恢复。

出站端点/路径/协议、TLS、SSRF、代理、响应大小和数据驻留受控；模型/工具输出视为不可信数据。企业服务账号 Scope、凭据/资源绑定和出站限制分别验证，账号技术能力不替代平台授权。

## 3. 安全运营

Security Incident 保存影响范围、Owner、原因、证据、遏制/恢复动作和状态。告警来源包括异常授权/访问、Secret 失效、审批绕过、注入、泄露和跨范围调用；严重事件可按已授权策略暂停相关准入或实例/Connector。

事件处理经过 OPEN→TRIAGED→CONTAINING→INVESTIGATING→RECOVERING→CLOSED 的受控状态，恢复须确认授权、凭据、业务事实和受影响数据。动作保留当前 Policy/审计，不能为应急停用访问控制或删除追踪。

暂停新写入不撤销已经发出的网络请求；未知业务效果、已发模型费用和补偿/结算待办保留受限处理入口。恢复 Operator 仅获得已批准的对账/补救权限，不自动成为全平台用户。

依赖/镜像扫描、配置/Secret 检查、备份权限和基线漂移记录纳入发布与运营。是否满足认证或法规需正式评估，文档和扫描报告不自动等于合规证明。

## 4. 保留、删除与员工撤权

数据类型至少区分：原件/解析/Chunk/索引、对话/记忆/Checkpoint、Agent/Workflow 快照、业务 Action/审批/Journal、Usage/Ledger、Trace 身份映射、Audit/备份。每类明确 Owner、用途、保留/删除依据和派生对象。

Deletion Plan/Job 记录目标、父子范围、授权/审批、法律保留、子项结果与重试。清理覆盖 DB、索引、缓存、对象/附件、派生内容和允许删除的身份映射；受理、部分完成和 VERIFIED 分开显示。

员工离职/成员撤销流程：禁用身份或撤销成员与资源权限 → 盘点本人负责的在途业务/UNKNOWN/预留 → 授权移交或核对 → 按制度删除/脱敏个人数据及派生对象 → 验证后续不可访问及必要留存。撤权不取消已发生的外部效果，移交不自动扩大新负责人的权限。

已经发生且依法/制度必须留存的业务审计或账目采取最小化、加密/访问隔离、有限期限；它们不是保留完整对话/附件的理由。legal_hold 要有范围、依据、Owner 和复审/到期，不提供任意“永久保存”开关。

恢复目录保留删除/停用 tombstone 与 Key/保留元数据。旧 Backup/Recovery Set 恢复后、开放用户访问前重新应用删除和访问规则，不能让已删除内容因灾备重新出现。

## 5. 验收

覆盖 用户/角色/KB/Workspace 越权、Token/服务身份 Scope、Prompt Injection、Secret/错误日志泄露、模型地区错误、轮换/失效中的恢复、高权限管理以及审批/业务效果处理。

删除/员工撤权测试覆盖派生数据、失败重试、法律保留、在途 Action/预算、密钥和旧备份恢复。证据可验证目标已不可访问，同时必要业务事实保持合法、可解释和受控留存。

安全事件演练记录遏制/调查/恢复时间、影响及动作审计；高危失败、成功越权/泄露/未批准写入按验收门禁处理，不能被整体质量分数掩盖。
