## 模型配置边界

P0-03 选择一个可调用的测试模型，只为验证 Adapter/Model Gateway 的流式、Embedding、错误、用量及维度行为；不冻结整个产品的模型选择。后续 Admin 管理 Provider、模型能力、参数与凭据安全引用，并发布 ModelConfig；RAG/Agent 消费平台 Model Gateway Contract，不读取临时 POC 模型名称。模型的向量维度来自具体配置和实际能力校验，切换 Embedding 时通过新 IndexVersion 重建及发布/回滚，不把不同模型或维度混写到已发布索引。

检索、任务和其他本地功能 POC 可以持续推进；缺少测试 Key 只阻塞真实模型调用及依赖该调用的质量验收。
