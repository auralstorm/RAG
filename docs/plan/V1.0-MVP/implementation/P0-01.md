# P0-01｜工程初始化记录

状态：2026-11-24 本地工程验收通过；远程 CI、PR 与评审尚未实际执行。

## 已落实的工程组织

- `backend`：FastAPI 应用工厂、经过校验的环境配置、存活检查和 API 测试。
- `frontend/apps/chat` 与 `frontend/apps/admin`：create-vite React TS 模板，独立端口与构建产物。
- `frontend/packages/ui`、`api-client`、`shared`：显式导出与 workspace 依赖，ESLint 检查应用/公共包依赖方向。
- 根目录 uv/pnpm 依赖锁、统一 Makefile、Ruff/ESLint/Prettier、Pyright/TypeScript、pytest/Vitest 检查入口。
- PR 模板、分支与评审规范、commitlint 和 CI 工作流；环境示例与基础凭据模式检查。

初始化与检查命令见 [根 README](../../../../README.md)。工具版本以版本文件、依赖声明与锁文件为准。当前工程只提供启动壳与进程存活接口，业务能力按版本任务推进。

## 验收证据

| 检查 | 实际结果 |
|---|---|
| `make install` | 根工作区按 uv/pnpm 锁文件安装成功；在不含 `.venv` 和 `node_modules` 的新临时目录重复安装成功 |
| `make check` | Ruff、ESLint、Prettier、Pyright、TypeScript、pytest、Vitest、双应用构建、仓库链接/基础凭据检查和 Git 差异检查全部通过；新目录再次通过相同检查 |
| `uv run --locked pytest` | 5 个测试通过，覆盖存活/OpenAPI、允许/拒绝 CORS、非法环境及通配 CORS 配置拒绝 |
| `pnpm test` | 6 个测试通过，覆盖两个应用的共享 UI、真实本地 HTTP 请求、上游错误、响应校验及取消传播 |
| `pnpm build` | Chat 与 Admin 分别生成各自 `dist`，workspace 公共包解析成功 |
| `make dev-backend`、`make dev-chat`、`make dev-admin` | 实际启动并通过 HTTP 检查，端口分别为 8000、5173、5174；验证后停止本次检查启动的进程 |
| commitlint | 拟用 P0-01 提交信息通过 CLI 校验 |

验证环境为 macOS Intel、Node 22.22.0、pnpm 10.34.9、Python 3.12.16、uv 0.13.8。新临时目录安装复用了下载缓存，未复制项目虚拟环境、node_modules 或构建产物。

已知构建提示：Ant Design 启动壳的主 JS 约 546 kB（gzip 约 178 kB），超过 Vite 默认 500 kB 分块提示；构建成功，后续业务路由按实际加载场景评估拆分，未提高提示阈值或将此结果视为性能 POC 通过。
