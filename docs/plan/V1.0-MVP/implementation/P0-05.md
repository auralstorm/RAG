# P0-05 MVP 需求与验收样例草案

截至 2026-11-24，首期文件类型已确认采用 Markdown、DOCX 和 PDF。以下草案供 PO、Tech Lead 和 QA 确认验收场景与输入。按 [V1.0 范围](../README.md) 和[最终验收场景](../06-完整研发实施计划与阶段验收标准.md#13-mvp-最终验收场景uat) 执行。

## 合成问答样例

将[设备借用指南](fixtures/equipment-guide.md) 上传到 `KB-GUIDE`，将[设备储备台账](fixtures/equipment-inventory.md) 上传到 `KB-INVENTORY`。两者分别发布首版。测试员工 A 可读两个 KB，员工 B 仅可读 `KB-GUIDE`。每次运行保存实际文档版本、索引版本、RAG 配置、员工及 Trace ID。表中的章节标识预期位置，运行时由 QA 核对实际生成的引用。

| ID | 员工与问题 | 期望答案与证据 |
|---|---|---|
| GD-01 常见问法 | B：借用测试平板，最晚几点归还？ | 借用当天 17:00 前归还。引用指南的“借用与归还”。 |
| GD-02 跨段落 | B：周一借平板，周二 10:30 归还，需要办什么？ | 周一 17:00 前提交延期申请，获批后周二 11:00 前归还，10:30 符合时间要求。引用指南的“借用与归还”和“延期”。 |
| GD-03 无答案 | B：测试平板损坏后的折旧赔偿公式是什么？ | 提示当前知识库没有赔偿公式。检查回复和引用未出现编造的公式或规则。 |
| GD-04 权限隔离 | A 与 B 分别提问：北区的备用平板保管在哪里？ | A 答“松石柜 B-17”并引用台账的“北区备用设备”。B 提示未找到证据。检查 B 的检索结果、回答、引用及直接来源请求均拒绝交付台账数据。 |
| GD-05 撤权 | 完成 GD-04 后撤销 A 对 `KB-INVENTORY` 的读取权限。查看原回答及引用，再次提问。 | 原回答正文、引用及来源不可读取。再次提问提示未找到证据，检索结果排除台账。 |

权限隔离与撤权逐案判定，任一次未授权内容返回即失败。业务验收人需确认真实语料和参考答案。QA 在 P3/P4 将业务样本和上述合成样本纳入检索与回答回归。

## Chat 与 Admin 验收流程

| 范围 | 优先级 | QA 执行与取证 |
|---|---|---|
| Chat 登录、问答、反馈与会话 | 必验 | 用正常及停用员工验证登录。正常员工执行 GD-01 至 GD-05，检查多轮追问、超长历史、停止生成、反馈、分页、删除和他人会话访问。保存关键请求、Trace ID 和期望状态。UAT-01、02、04、05。 |
| Admin 知识资产与索引 | 必验 | 上传三种已确认格式。检查状态直到发布，模拟解析或发布失败后重试，检查失败时仍可查询旧版本。验证删除后的访问及清理结果。UAT-02、03、10。 |
| Admin 用户、角色与可观测性 | 必验 | 用超级管理员、知识库管理员、审计员分别访问界面与 API。核对权限制约、Trace 查询、溯源二次确认、审计及离职清理。UAT-01、05 至 09。 |
| Admin 仪表盘、供应商、模型与配置 | 必验 | 对照受控数据核验聚合指标。创建与停用模型，查看密钥掩码及变更审计。验证配置和索引版本可按发布记录回查。UAT-06、09、10。 |
| 平台稳定性、评测与 Mock Tool | 必验 | 复现故障、恢复、回滚与评测回归，保存版本、负载和结果。用开发或测试环境验证 Mock Tool 的授权、拒绝与截止时间。UAT-02、04、09、10，以及 [Mock Tool 契约](../../../api/mock-tool-contracts.md)。 |

## 冻结所需输入

| 待确认项 | 责任角色 | 确认基于 |
|---|---|---|
| 首期 OAuth/OIDC 供应商 | PO、身份系统负责人 | 确认可用测试环境、员工与停用账号、稳定主体标识及必要声明。 |
| 真实语料与问答 | 业务验收人、QA | 覆盖三种文件格式、扫描 PDF 比例、真实访问分组及关键问题的参考答案和原文定位。 |
| 单文件上限、KB/文档数量及并发假设 | PO、Tech Lead | 记录目标环境、语料体量、并发问答与并行入库负载。 |
| 性能及问答质量门槛 | PO、Tech Lead、QA | 根据目标环境 POC、业务 Golden Dataset 与性能验收计划确认门槛及可复现口径。[P5-10 性能、容量与稳定性测试](../06-完整研发实施计划与阶段验收标准.md#p5-10-性能容量与稳定性测试) |
