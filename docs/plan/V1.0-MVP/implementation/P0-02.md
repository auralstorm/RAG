# P0-02｜Docker 开发环境与就绪检查

状态：2026-11-24 本地开发和测试环境验收通过；远程 CI/PR/评审尚未实际执行。

## 实现

- 开发和测试使用独立 Compose 项目、端口、网络、五个持久化卷与随机凭据；凭据文件 0600 且不进入 Git。
- PostgreSQL 初始化独立 Phoenix 数据库，Redis 开启 AOF，RabbitMQ 使用稳定主机名与节点名称，Elasticsearch 单节点，MinIO 幂等初始化存储桶，Phoenix 使用 PostgreSQL 持久化。
- `make infra-up/down/status/init/reset/test` 提供启动、状态、初始化、保留数据的停止、清空数据的重置与独立测试入口。
- `/health/ready` 并发检查六个依赖，失败/超时返回 503，返回内容只包含状态。共享 SDK 客户端由应用生命周期管理，SQL/AMQP 短连接每次检查后关闭。
- 常规 `make check` 不要求 Docker；CI 另执行 `make infra-test`，显式验证 Docker 依赖。

## 验收证据

| 检查 | 实际结果 |
|---|---|
| `make infra-test` | 1 个真实集成测试通过（290.91 秒），包含首次启动、保留卷重建、六个依赖停机/恢复以及测试数据重置 |
| 持久化 | PostgreSQL 行、Redis Key、RabbitMQ 持久消息、MinIO 对象及 Elasticsearch 文档在容器重建后保持一致；Phoenix 数据库随 PostgreSQL 持久化 |
| 依赖故障 | 分别停止 PostgreSQL、Redis、RabbitMQ、Elasticsearch、MinIO、Phoenix，API 均返回 503，对应依赖为 false；进程存活接口仍返回 200 |
| 重置与清理 | 测试重置后 PostgreSQL 探针表与 Redis Key 消失，就绪恢复；测试结束清理 `enterprise-rag-test` 的容器、网络和卷 |
| 配置初始化 | 同一配置再次初始化内容保持一致，文件权限 0600 |
| `make check` | 严格类型、lint/格式、9 个普通后端测试、6 个前端测试、双应用构建及仓库检查通过 |
| `make infra-up` | 开发环境六个服务全部 healthy，存储桶初始化完成，保持运行供后续开发使用 |
| 默认开发配置与 API | 实际 API `/health/ready` 返回 200，六个依赖状态均为 true |
| 原有容器 | `rag-qdrant-1`、`rag-postgres-1`、`rag-redis-1` 的容器 ID 和运行状态保持一致 |

验证环境：macOS Intel，Docker 29.9.3 / Compose 5.7.0，Docker Desktop 分配约 8 GB 内存。开发服务与原有其他项目的容器使用不同端口和数据卷。

实际服务版本：PostgreSQL 16.16、Redis 7.4.12、RabbitMQ 4.4.1、Elasticsearch 9.2.0、MinIO `RELEASE.2025-09-07T16-13-09Z`（源码构建）、Phoenix 22.0.1。初始 PostgreSQL shell 挂载脚本的执行权限问题已通过只读 SQL 初始化文件修复，最终测试在重新初始化的数据卷上通过。

## 版本与边界

后续维护核验已发现 MinIO 社区服务端归档、停止维护及当前版本早于已知安全修复版的问题，已登记为 [POC-08](../04-poc-acceptance-and-adr.md#11-poc-08-对象存储维护安全与选型复核)。上述本地功能验收结果保留，对象存储安全与长期维护准入按该 POC 的关闭条件处理。

镜像摘要见 [images.env](../../../../infra/compose/images.env)，运行与数据清理规则见 [基础设施说明](../../../../infra/README.md)。MinIO 在官方镜像地址无法访问时使用校验过的官方发行源码构建，发行标签与源码 SHA-256 已固定；构建基础镜像按摘要固定，Go 模块使用源码中的版本与校验信息。

这是本地开发/测试环境。真实模型供应商、代表性文档解析、检索与 Trace 链路验收属于 P0-03；生产认证/TLS、容量和运维配置按后续任务交付。服务端 CI/PR/非作者评审以实际执行结果为准。

后续对象存储已按用户决定替换为 RustFS，当前编排及兼容/回退验证见 [替换实施记录](rustfs-object-storage.md) 和 [ADR-0015](../../../adr/0015-rustfs-object-storage.md)。本文件中的 MinIO 测试数据为替换前的历史证据。
