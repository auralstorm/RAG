# Chat 本地演示

日期：2026-11-25。按用户要求先完成员工端 IT 知识助手演示，保留 [V1.0 实施计划](../06-完整研发实施计划与阶段验收标准.md) 的正式业务交付顺序。

## 本次交付

- Chat 应用接入固定版本 `@ant-design/x`、`@ant-design/x-markdown` 2.10.0 与 `@ant-design/icons` 6.3.4，沿用 Ant Design 6.7.2；`XProvider` 合并两套中文语言包。
- 使用 Welcome、Prompts、Conversations、Sender、Bubble.List、ThoughtChain.Item、Actions.Copy 与 Attachments 组成演示。展示常见问题、推荐提问、模拟流式 Markdown、停止、重试、复制和反馈。
- 支持创建、切换、重命名和删除会话。切换或新建会话停止旧生成并保留部分回复；删除会话和页面卸载清理定时器。最后一个会话删除后保留可提问的空会话。
- 会话按钮、菜单、发送、停止和反馈支持键盘访问。反馈使用 Ant Design Button，保持可聚焦节点与 `aria-pressed`；2.10.0 的 Actions.Feedback 内部点击元素不提供同等键盘行为。生成状态单独播报，避免逐字重复朗读答案。
- 桌面显示侧栏，700px 以下使用抽屉；抽屉继承页面主题变量。消息区与输入框使用不同的会话 key，避免切换后残留旧消息。

入口位于 [App.tsx](../../../../frontend/apps/chat/src/App.tsx)，页面和模拟状态在 [chat](../../../../frontend/apps/chat/src/chat/ChatPage.tsx) Feature 内，公共包和 Admin 不依赖这些演示模块。

## 使用与边界

在根目录运行 `make dev-chat`，访问 <http://127.0.0.1:5173>。演示不需要启动后端或 Docker。

所有答案来自固定示例；未覆盖的问题提示选择推荐问题。页面标明“本地演示 · 回答为示例内容”。会话、反馈和附件列表仅保存在当前页面内存，刷新后重置。附件仅展示本地文件信息，不上传、不解析，也不作为问题输入；切换会话清空输入框与附件列表。

Markdown 开启原始 HTML 转义和净化，禁止图片标签，外链在新页打开。当前示例没有真实来源或 Trace，未生成虚构引用。正式登录、服务端授权、HTTP/SSE、RAG、引用、TraceId、持久化及业务错误恢复仍由相应阶段实现。本演示不作为 P1 身份闭环或 P4-08 验收通过的证据。
