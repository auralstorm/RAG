## 目录与职责

Chat 和 Admin 的应用入口位于各自 `src/app/`，全局样式位于 `src/styles/`，`main.tsx` 仅挂载应用。Chat 私有实现按 [前端规范](../../../standards/前端代码规范.md) 组织：

```text
src/
├── app/                      # App、Provider、回复来源初始化
├── features/chat/
│   ├── pages/                # ChatPage 与用例编排
│   ├── components/           # 欢迎页、会话列表、消息区、输入框
│   ├── hooks/                # useChat 与行为测试
│   ├── styles/               # Feature CSS Modules
│   ├── prompts.ts            # 推荐问题与分组
│   └── types.ts              # 本地视图类型与回复来源接口
├── mocks/                    # 开发固定答案与模拟生成
├── styles/                   # 全局基础样式
└── main.tsx
```

入口见 [App.tsx](../../../../frontend/apps/chat/src/app/App.tsx)，页面见 [ChatPage.tsx](../../../../frontend/apps/chat/src/features/chat/pages/ChatPage.tsx)。源码与文件名不再使用旧临时命名。Admin 当前仍为初始化壳；公共包位置、正式 exports 和依赖方向保持一致。路由由后续 P1-02 登录任务建立，store 按实际需求增加。

## 回复来源与交互

`useChat` 接收 `ChatReplySource | null`，管理会话、消息与反馈。回复来源提供 `streamReply(question, AbortSignal)` 增量文本和展示说明；这是 Feature 内部接口，不是平台 HTTP/SSE 契约。固定答案及 70ms/12 字符的模拟节奏均在 `mocks/` 内。

应用只有同时满足 Vite `DEV` 和 `MODE=development` 才动态导入 mocks；测试显式注入。生产构建、测试模式和其他运行模式默认不加载模拟来源。开发页面显示“开发环境 · 回答为模拟内容”，生产页面显示“知识问答接口尚未接入”，并禁用发送、推荐问题提交和附件预览。初始化具有加载与失败提示。

开发模式支持推荐提问、流式 Markdown、停止、原消息重试、复制、反馈及会话创建/切换/重命名/删除。切换、新建、删除和卸载取消旧请求；即使来源不遵守取消，迟到输出也不能写入界面。生成异常保留部分回答并显示失败，可重试；不显示来源错误详情。

界面沿用 Ant Design X / X Markdown 2.10.0 和 Ant Design 6.7.2。会话、发送、停止及反馈保持键盘访问，生成状态独立播报。桌面侧栏与 700px 以下抽屉保持原布局，320px 快捷提问换行。Markdown 转义原始 HTML 并净化，禁止图片标签，外链在新页打开。

会话和反馈暂存内存，刷新后重置；切换会话清空输入草稿和附件列表。附件仅展示本地文件信息，不上传、不解析，也不参与问答。当前没有真实来源或 Trace，不生成虚构引用。
